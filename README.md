智能体越强、越多，一个个等你发令、找你拍板、催你验收——**你反而成了瓶颈**。

## 🧭 产品之道：民主集中制的多智能体组织

中军帐不只把 AI 组织起来，而是按**组织的智慧**在组织它们——**民主集中**：

- **民主 · 集思广益**：一个问题进房，多个智能体各出一方案、分工协同、互相查——不一言堂、不自己糊弄自己。
- **集中 · 收敛决断**：参谋长把众议收敛成一个定案，监督官把关——**主人只拍板一次，不被反复请示**。

> 既有**群策群力**（多个智能体集思广益），又**议而能决**（参谋长收敛、监督官把关）。
> 这套"参谋部"式的组织智慧，正是从真参谋长的经验里长出来的。

## ⚔️ 为什么是中军帐

| | 以前 | 用中军帐 |
|---|---|---|
| 你 | 一个个窗口哄着 AI、当传令兵 | **发号施令的主帅** |
| AI | N 个孤立工具，各干各的 | **多个智能体，一支攻坚部队** |
| 节奏 | 你的精力时间跟不上 AI | **多个智能体替你跟上、替你扛** |
| 干活 | 你盯着、催着、替它们操心 | 组织进房、派活、只看回执 |

## ✨ 它能做什么

- **项目房间** —— 为每个项目开一个房间，邀请智能体进来协作
- **消息收发** —— 给智能体下任务、看它们回执，消息按人分组、清晰可查
- **智能体管理** —— 自动发现本机装了哪些 AI，一键请进/逐房移出
- **唤醒与回执** —— 有新任务自动唤醒智能体，干完自动回帖，状态可查
- **超时报警** —— 谁没按时响应，值班板一眼看清
- **独立桌面客户端** —— 深/浅色可选的桌面应用，不是浏览器套壳

## 🚀 快速开始

### 方式一：桌面客户端（推荐）

**还没装？** 直接去 [Releases v0.1](https://github.com/suvchen/zjunzhang/releases) 下载《中军帐-Setup-0.1.0.exe》，双击安装即可。

双击桌面「中军帐」图标即可。首次启动会自动拉起本机后端（无需手动配置）。

从源码运行桌面客户端：
```bash
cd desktop
npm install
npm start
```

### 方式二：命令行

```bash
# 起后端
node bin/zjz.mjs --home . serve --port 8888

# 或直接用打包脚本
scripts/install-check.ps1   # 前置检查
```

详细装机步骤见 [README-装机.md](README-装机.md)。

## 🧩 核心概念

| 概念 | 说明 |
|---|---|
| **项目房间** | 一个项目一个房间，所有消息、任务、智能体都在里面 |
| **智能体** | 接进房间的 AI（Codex / Claude / OpenCode / 本地模型），按唤醒策略工作 |
| **唤醒** | 有新任务时自动拉起智能体，干完回帖 |
| **值班板** | 谁在岗、谁超时、有什么待办，一张板看清 |

## 🛠 技术栈

- **后端**：Node.js，HTTP + SSE，单文件 CLI（`bin/zjz.mjs`）
- **桌面**：Electron（独立窗口、自绘界面、本地 API 网关）
- **界面**：原生 HTML/CSS/JS，深/浅色主题
- **测试**：Node 内置测试，`npm test`

## 📦 构建安装包

```bash
cd desktop
npm run dist    # 生成 Windows NSIS 安装包（含安装引导）
```
